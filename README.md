# 📚 Sistema Biblioteca

Sistema web desenvolvido para auxiliar no gerenciamento de uma biblioteca, permitindo organizar livros, alunos e empréstimos de forma simples, rápida e intuitiva.

O projeto foi desenvolvido como atividade prática de desenvolvimento web, utilizando tecnologias fundamentais de **Front-End**, com foco em organização de código, criação de interfaces, responsividade e interação com o usuário.

---

## 📌 Sobre o projeto

O **Sistema Biblioteca** é uma aplicação web criada para representar um sistema básico de gerenciamento de uma biblioteca.

Através da plataforma, o usuário pode acessar diferentes áreas do sistema para:

- 📚 Gerenciar livros;
- 👨‍🎓 Gerenciar alunos;
- 🔄 Controlar empréstimos;
- 📝 Realizar cadastros;
- 📊 Visualizar informações cadastradas;
- 📱 Utilizar o sistema em diferentes tamanhos de tela.

A interface foi desenvolvida buscando manter uma aparência moderna, organizada e fácil de utilizar.

---

## 🎯 Objetivo

O principal objetivo do projeto é desenvolver uma aplicação web funcional que simule o gerenciamento de uma biblioteca.

Além disso, o projeto permite colocar em prática conhecimentos relacionados a:

- Estruturação de páginas HTML;
- Estilização com CSS;
- Programação com JavaScript;
- Organização de arquivos;
- Navegação entre páginas;
- Formulários;
- Tabelas;
- Responsividade;
- Versionamento de código com Git e GitHub.

---

# ⚙️ Funcionalidades

## 🏠 Página inicial

A página inicial apresenta:

- Nome e identidade visual do sistema;
- Menu de navegação;
- Apresentação do sistema;
- Imagem ilustrativa de uma biblioteca;
- Botões de acesso rápido;
- Cards com as principais funcionalidades;
- Seção informativa;
- Rodapé.

---

## 📚 Gerenciamento de livros

A área de livros permite cadastrar informações como:

- Título;
- Autor;
- Ano de publicação.

Após o cadastro, os dados podem ser apresentados em uma tabela dentro do sistema.

---

## 👨‍🎓 Gerenciamento de alunos

A área de alunos permite registrar informações dos estudantes, como:

- Nome;
- Matrícula;
- Turma.

Os dados cadastrados são apresentados de maneira organizada.

---

## 🔄 Gerenciamento de empréstimos

A área de empréstimos permite registrar informações relacionadas à retirada de livros, incluindo:

- Aluno;
- Livro;
- Data do empréstimo.

Essa funcionalidade tem como objetivo facilitar o controle das movimentações da biblioteca.

---

## 📝 Cadastro

O sistema também possui uma página destinada aos cadastros, permitindo centralizar as informações necessárias para utilização da aplicação.

---

# 💻 Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

### HTML5

Utilizado para criar a estrutura das páginas e organizar os elementos da aplicação.

### CSS3

Utilizado para:

- Criar o design da aplicação;
- Definir cores;
- Organizar os elementos;
- Criar cards;
- Estilizar formulários;
- Estilizar tabelas;
- Criar botões;
- Desenvolver o layout responsivo.

### JavaScript

Utilizado para adicionar interatividade ao sistema, principalmente nos formulários e no cadastro de informações.

### Git

Utilizado para realizar o versionamento do projeto e registrar as alterações realizadas durante o desenvolvimento.

### GitHub

Utilizado para armazenar o código-fonte do projeto e acompanhar seu desenvolvimento através de commits e branches.
